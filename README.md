# 📈 Polymarket Trader — Simulação de Carteira

Trader de simulação do Polymarket: carteira fictícia, compra/venda de shares, P&L em tempo real e portfolio. Treine trading sem arriscar dinheiro real.

## Recursos

- 💵 **Carteira fictícia** — saldo inicial configurável (default $1,000)
- 🛒 **Compra e venda** — buy/sell shares de Yes ou No
- 📊 **P&L em tempo real** — lucro/prejuízo por posição e total
- 📋 **Portfolio** — posições abertas com preço médio e valor de mercado
- 📜 **Histórico de trades** — log completo de todas as operações
- 🔍 **Mercados reais** — busca mercados do Polymarket (API Gamma)
- 📈 **Gráficos** — alocação e performance da carteira (Canvas)
- 💾 **Offline** — dados salvos no navegador (localStorage)
- 🌙 **Tema escuro** nativo
- 📱 **Responsivo** — celular, tablet e desktop

## Tech Stack

- HTML5 + CSS3 + JavaScript vanilla
- Polymarket Gamma API (mercados e preços)
- Canvas API para gráficos
- localStorage (prefixo `pm_`)

## Como usar

Abra `index.html` no navegador. Comece com $1,000 fictícios. Pronto.
